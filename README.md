# Web Components with LitElement and Vite

This project is a basic example to familiarize myself with Web Components using LitElement, in this case, utilizing Vite as the build tool.

## Overview

This project demonstrates how to create and use Web Components with LitElement. It includes a simple table component that dynamically renders data fetched from an API. The project setup uses Vite for fast and efficient development.
